### ローカルファーストのリアルタイム会議文字起こし。端末内で処理し、プライバシーを守り、GPU で高速化。

マイク音声**と**会議の音声を、話者別のリアルタイム文字起こしに。隣には AI アシスタント。すべてあなたの端末上で動作します。クラウド不要。アップロード不要。アカウント不要。

**Wisp** は、あらゆる会話をタイムスタンプと話者ラベル付きの読みやすい文字起こしにリアルタイムで変換し、同時に AI アシスタントを動かします。既定では、すべての音声データとモデルが端末内にとどまります。数秒でインストールでき、追加の設定は**一切不要**。仮想オーディオドライバーもカーネル拡張も必要ありません。Apple Silicon では Metal と Neural Engine、Windows ではネイティブのループバックを活用し、各プラットフォームのハードウェアに最適化されています。

> 🔒 **プライバシーを守る設計** · ⚡ **アーキテクチャに最適化** · 🎛️ **自由に設定** · 🪶 **インストールしてすぐ使える**

## 🎙️ リアルタイムの会議アシスタント

Wisp の中核となる機能です。しかも高速です。

- **1 秒未満の遅延でストリーミング文字起こし。** 発話に合わせて文字が表示され、途中結果から確定行へと更新されます。各行にはタイムスタンプが付きます。「停止して初めて結果が見える」方式ではありません。
- **誰が話しているかを識別。** 端末内の話者分離が、各行にリアルタイムで **あなた** / **相手**、または **話者 1 / 2 / 3** のラベルを付けます。逐次更新する話者の重心ベクトルにより、長時間の通話でも話者識別を安定させます。
- **双方の音声を取得。** マイクと会議のシステム音声を 1 つのタイムラインに統合。**WebRTC AEC3 によるエコー除去**で、相手の声がマイクから再入力されるのを防ぎます。ワンクリックで使え、ループバックドライバーのインストールは不要です。
- **🤖 AI Assist: 通話中の「もうひとつの頭脳」。** 生成中の内容を逐次表示するアシスタントパネルです。
  - 会議の進行に合わせて更新される**継続的な要約**、**アクションアイテム**、**決定事項**、**未解決の質問**
  - そのまま送信できる**フォローアップメール**の下書き
  - **リアルタイムのヒント**とサービス業向けテンプレート。営業への助言、サポートの案内、感情や口調のリアルタイム監視
  - 話者分離を踏まえた文脈で、*誰が何を言ったか*を把握。更新頻度を調整し、邪魔にならず役立つ支援を提供

> 自分の LLM エンドポイント（ローカルまたはクラウド）を利用できます。アシスタントはモデルに依存せず、温度、ペナルティ、最大トークン数などを細かく設定できます。

## 📄 最先端のファイル文字起こし

音声ファイルや動画ファイルをドロップするだけで、信頼できる文字起こしを作成します。

- **既定で精度を優先。** Whisper **large-v3-turbo** を使用。より大きなモデルや量子化版にもワンクリックで切り替えられます。
- **話者分離。** *誰が何を言ったか*を識別し、**単語単位のタイムスタンプ**と話者の割り当てを提供します。
- **カスタム語彙 / 用語の優先認識。** 人名、製品名、専門用語を指定して、正しく文字起こしされるようにします。
- **入力音声をクリアに。** ニューラルノイズ除去と VAD による選別で、モデルへの入力前に非音声区間を取り除きます。
- **任意のローカル LLM による文章整形。** 端末の外にデータを出さずに、句読点や言いよどみを整えます。
- **構造化された Markdown エクスポート。** 要約、話者、タイムスタンプ付きタイムラインを、すぐ共有できる形式で出力します。
- **進捗をリアルタイム表示。** 内部の進み具合が分かりにくいデコード段階でも進捗を表示し、止まったバーを見つめ続ける必要はありません。

## 🧠 プライベートな検索可能メモリー

Wisp が文字起こししたすべての会議は**ローカルのノートライブラリ**に保存されます。端末内だけで、すべてのノートを*意味*で横断検索できます。

- **意味検索とキーワード検索を統合。** *「予算の議論」*と検索すれば、その言葉が実際に発話されていなくても適切なノートを見つけます。SQLite FTS5 のキーワード照合とベクトル類似度を組み合わせたハイブリッド検索です。各結果には、キーワードのハイライトと意味的な一致の信頼度スコアで、*なぜ一致したか*を表示します。
- **最先端のローカル埋め込みモデルを選択。** 設定画面から、端末内で動作する埋め込みモデルをダウンロード、切り替え、削除できます。
  - **Qwen3-Embedding 0.6B**: 最先端の、指示に合わせて調整された**デコーダー型**埋め込みモデル
  - **BGE-M3**: 1024 次元、100 以上の言語に対応し、中国語・日本語・韓国語に強いモデル
  - さらに **GTE multilingual**、**Multilingual E5**（small / base / large）、**BGE-Chinese** に対応

  モデル切り替え時は、ライブラリのインデックスを**アトミックに**再構築します。切り替えが中断・失敗しても、既存のインデックスを破損させません。
- **データは端末の外に出ません。** ONNX Runtime を通じて、ノートの埋め込み生成と検索をローカルで行います。特定の用途でホスト型の埋め込みモデルを使いたい場合は、OpenAI 互換のクラウドモデルを自分の API キーで**明示的に有効化**できます。

## 🔒 ローカルファーストで、プライバシーを守る

文字起こし、話者分離、ノイズ除去、VAD は、`sherpa-onnx` と Metal / ANE により、すべて**端末内**で動作します。音声がネットワークに送られることはありません。モデルは**インストールを選択したときだけ** Hugging Face から取得し、ローカルにキャッシュします。

特定の用途でホスト型モデルが必要な場合は、クラウドエンジン（OpenAI、Gemini、Groq、Qwen、Speechmatics）を**明示的に有効化**できます。自分の API キーを追加してローカルに保存し、それ以外の処理は引き続きローカルで行います。

## 🍎 Apple Silicon に最適化

Wisp は単に「Mac で動く」だけではありません。アーキテクチャに合わせて最適化されています。

- **Metal GPU 推論。** Whisper エンジン（whisper.cpp）を Metal 経由で GPU 上で実行し、CPU と比べて大幅に高速化します。
- **Apple Neural Engine。** Whisper のエンコーダーを **Core ML** で実行し、最も重い処理段階を **ANE** に任せることで、GPU と CPU の負荷を軽減します。
- **ユニファイドメモリアーキテクチャ。** Apple Silicon の共有メモリにより、CPU、GPU、ANE 間で**ゼロコピー**のデータ受け渡しが可能です。PCIe 経由の往復が不要になり、遅延と消費電力を抑えます。
- **Apple SpeechAnalyzer。** macOS 26 では、Apple 内蔵の端末内音声処理フレームワークを、正式なエンジンの選択肢として利用できます。ANE で高速化され、**モデルのダウンロードも不要**です。
- **ScreenCaptureKit。** カーネル拡張なしで、権限に基づくネイティブのシステム音声取得を行います。

エンジン、モデル、デコードの実行間隔は、**端末に合わせて自動選択**されます。コア数、RAM、GPU / Neural Engine の性能を考慮し、すぐに高速で使えるうえ、必要に応じて調整できます。

## 🎛️ アプリに合わせるのではなく、自分に合わせて設定

エンジンのダウンロードを強制しません。使い始める前に数 GB の「要約エンジン」を必須とすることもありません。Wisp はすぐに動作し、何を追加するかは**あなた**が決めます。

- **カタログから好きなモデルを選択。** 速度優先でも精度優先でも、モード（リアルタイム / ファイル）ごとに切り替えられます。
- **自分の音声モデルをインポート。** sherpa-onnx の `.onnx` グラフ、または Whisper の GGML / GGUF ファイルを選択できます。Wisp が検証し、対応するトークン、エンコーダー / デコーダー / ジョイナーのグラフ、外部重みも自動的に取り込みます。
- **地域を問わず使えるダウンロード。** Hugging Face とミラー間の自動フェイルオーバー、中断ファイルからの再開、回数制限付きの再試行、環境変数によるプロキシ設定や HTTP / SOCKS プロキシに対応します。**設定 → モデルのダウンロード**から、ミラーやプロキシを随時変更できます。同じ方針が、文字起こし、話者、ノイズ除去、Core ML、埋め込みの各モデルに適用されます。
- **不要なモデルを削除。** モデル選択画面からワンクリックで削除し、ディスク容量を取り戻せます。
- **細かく設定。** 文字起こし言語、精度と速度のプロファイル、VAD による選別、ノイズ除去、デコードのしきい値、話者分離、カスタム語彙を調整できます。1 つのプリセットに縛られません。
- **分かりやすいモデル選択。** 端末で実行できないモデルを明示し、ダウンロード前にサイズと必要なハードウェアの目安を確認できます。

### モデルの保存先

**設定 → ストレージ**で、既存の読み書き可能なフォルダーをモデル保存先として選択できます。
その配下の `models/`、`embed-models/`、`custom-models/` を使用します。
保存先の変更は**次回のアプリ起動時**に反映され、実行中のダウンロードやエンジンは現在の場所を引き続き使用します。
**既定の保存先に戻す**操作も、次回起動時に反映されます。

既存ファイルは自動移行しません。インストール済みモデルを引き続き使用する場合は、Wisp を終了し、
画面に表示されている現在の場所から新しい保存先へ、この3つのフォルダーを手動で移動してから再起動してください。
隠しマーカー、中断したダウンロード、Core ML ファイル、カスタムモデルの登録情報を含め、フォルダー全体を保持してください。
移動先に同名のフォルダーがある場合は、内容を確認せずに上書きしないでください。
ノート（`library.db`）、API キー、設定は元のアプリデータの場所に残ります。

指定したフォルダーが見つからない、またはアクセスできない場合でも、Wisp は起動してエラーを表示します。
別の保存先へ自動的に切り替えることはせず、ローカルモデルの操作を停止します。
保存先を再接続するか、設定で別のフォルダーを選択して再起動してください。

## 🔌 追加設定・依存ソフトウェア不要

- **macOS:** **ScreenCaptureKit** でシステム音声を取得。*BlackHole、Loopback、仮想オーディオデバイスは不要です。*
- **Windows:** ネイティブの **WASAPI ループバック**でシステム音声を取得します。
- ワンクリックでマイクと会議音声を同時に取得し、エコーを除去します。アプリをインストールして起動するだけで、準備は完了です。

## 🪶 その他の機能

- **音声入力。** グローバルなプッシュ・トゥ・トークで音声をテキストに変換し、ネイティブのテキスト挿入で*あらゆるアプリ*に入力します。
- **小さなインストーラー。** Windows は 8 MB、macOS は 22 MB。機械学習ランタイムが基本部分を占め、モデルは必要に応じてダウンロードします。
- **多言語 UI。** 英語、簡体字中国語、繁体字中国語に対応します。
- **クロスプラットフォーム。** 1 つのコードベースで macOS（Apple Silicon）と Windows（x64）に対応します。

## 📦 インストール

**[リリースページ](https://github.com/ppXD/Wisp/releases)**から最新ビルドをダウンロードしてください。

### macOS（Apple Silicon）
1. `Wisp_<version>_aarch64.dmg` をダウンロードして開き、**Wisp** を Applications フォルダーにドラッグします。
2. 現在のビルドは未署名のため、隔離フラグを一度解除します。
   ```sh
   xattr -cr /Applications/Wisp.app
   ```
3. Wisp を起動します。要求されたら、**マイク**と**画面収録**（システム音声の取得用）の権限を許可してください。

> Apple Silicon（M1 以降）専用です。Intel Mac には対応していません。GPU / Neural Engine とシステム音声の処理には、最新の Apple Silicon 向け SDK が必要です。

### Windows（x64）
1. `Wisp_<version>_x64-setup.exe` をダウンロードして実行します。
2. Wisp を起動し、要求されたらマイクへのアクセスを許可してください。

## 🛠️ ソースからビルド

**Rust**（stable）、**Node** 20 以降、各プラットフォームのビルドツール（macOS は Xcode + `meson` / `ninja`、Windows は MSVC）が必要です。

```sh
git clone --recurse-submodules https://github.com/ppXD/Wisp.git
cd Wisp/app
npm install
npm run tauri dev      # アプリを起動
npm run tauri build    # インストーラーを生成
```
